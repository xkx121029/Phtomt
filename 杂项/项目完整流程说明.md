## 一、项目概述

**Happy Phone Agent（快乐手机助手）** 是一款基于 Android 的 AI 手机自动化 Agent 应用。核心能力：用户输入自然语言任务描述，AI 读取手机屏幕，自动完成操作（点击、输入、滑动、打开应用等）。

**技术栈：**
- Kotlin + Jetpack Compose（Material 3 Expressive UI）
- Koin DI + DataStore 持久化
- Shizuku（系统级权限）+ 无障碍服务（Accessibility Service）
- OpenAI 兼容 AI API（GLM 等）
- 双通路视觉：外挂 3B 端侧模型 + 云端视觉模型

**代码规模：** 约 81 个主工程 Kotlin 源文件，核心 AgentEngine 约 1980 行（+ 测试代码）。

## 三、核心数据模型

### 3.1 AgentIntent — AI 输出的意图

AI 在 JSON 中输出的意图，描述"做什么"和"对什么做"：

```kotlin
data class AgentIntent(
    val intent: String,              // 意图类型（open_app/tap/input/...）
    val target: AgentIntentTarget?,  // 目标 { by: "text", value: "发送" }
    val app: String?,                // 应用名/包名
    val text: String?,               // 输入文字
    val direction: String?,          // 滑动方向
    val waitMs: Long?,               // 等待时长（ms）
    val reasoning: String?,          // AI 思考过程
    val expected: String?,           // 执行后预期
    val confidence: Double?,         // 置信度 0~1
    val pageFingerprint: String?,    // 页面指纹
    val needsConfirmation: Boolean,  // 是否需用户确认
)
```

### 3.2 AgentAction — 端侧内部动作命令

转译层输出，描述"怎么做"：

```kotlin
data class AgentAction(
    val type: String,          // 动作类型（launch/tap/type/...）
    val x: Int?, val y: Int?, // 像素坐标
    val target: ActionTarget?, // 目标描述 {method, value}
    val packageName: String?,  // 应用包名
    val command: String?,      // shell 命令（Shizuku 模式）
    val reason: String?,       // 用户可见的执行说明
    val reasoning: String?,    // AI 思考过程
    val expected: String?,     // 预期结果（验证对比用）
    val pageFingerprint: String?, // 页面指纹
)
```

### 3.3 AgentState — Agent 运行状态

```kotlin
data class AgentState(
    val isRunning: Boolean,
    val task: String,
    val phase: Phase,       // IDLE → OBSERVING → THINKING → ACTING → DONE/ERROR
    val message: String,
    val stepCount: Int,
    val lastAction: AgentIntent?,
)
```

## 四、完整执行流程

### 阶段一：任务规划

```
用户输入任务描述（如"打开微信给张三发'你好'"）
        │
        ▼
┌─ 模板匹配 ──────────────────────────────────────────────┐
│ TaskStore.searchSimilarTasks(task)                      │
│   ├─ 命中历史模板 → 直接展示计划，等待用户批准           │
│   └─ 未命中 → 进入 AI 规划                              │
└─────────────────────────────────────────────────────────┘
        │
        ▼
┌─ AI 流式规划 ───────────────────────────────────────────┐
│ CloudAgent.planStream(task)                             │
│   ├─ 调用 AI API（temperature=0.3）流式输出计划          │
│   ├─ 歧义检测：AI 识别不确定点 → 生成澄清问题            │
│   │     └─ 悬浮窗弹出澄清面板 → 用户选择 → 重新规划     │
│   └─ 生成 TaskPlan（步骤列表 + 每步意图）                │
└─────────────────────────────────────────────────────────┘
        │
        ▼
┌─ 用户批准 ──────────────────────────────────────────────┐
│ 悬浮窗展示计划摘要                                       │
│   ├─ 用户批准 → 进入执行循环                            │
│   └─ 用户拒绝/修改 → 返回重新规划                       │
└─────────────────────────────────────────────────────────┘
```

### 阶段二：ReAct 执行循环（每步）

```
┌─ 开始执行循环（最多 maxSteps 步）─────────────────────────┐
│                                                          │
│  ┌─ Step 1: 观察（Observe）──────────────────────────┐   │
│  │                                                    │   │
│  │  AgentAccessibilityService.captureScreen()         │   │
│  │    ├─ 抓取无障碍元素树（UiElement[]）               │   │
│  │    ├─ 获取当前前台包名、屏幕尺寸                    │   │
│  │    └─ 构建 ScreenSnapshot                          │   │
│  │                                                    │   │
│  │  PageAnnotator.annotate(snapshot)                  │   │
│  │    ├─ 推断页面类型（search_page/product_detail/...）│   │
│  │    ├─ 生成上下文提示（"这是一个搜索结果页"）        │   │
│  │    └─ 标注控件优先级（high/medium/low）            │   │
│  │                                                    │   │
│  │  安全检查：SensitivePageDetector.isSensitive()     │   │
│  │    └─ 支付/银行/私密页面 → 强制 READONLY 模式      │   │
│  │                                                    │   │
│  └────────────────────────────────────────────────────┘   │
│                          │                               │
│                          ▼                               │
│  ┌─ Step 2: 本地决策（Local Decision）─────────────────┐  │
│  │                                                     │  │
│  │  LocalDecisionEngine.decide(snapshot)               │  │
│  │    ├─ dialog_overlay → 自动点击"允许/确定"          │  │
│  │    ├─ ad_with_countdown → 自动跳过广告              │  │
│  │    ├─ loading → wait 1200ms                         │  │
│  │    ├─ error → 点击"重试"                            │  │
│  │    └─ completion（元素≤5）→ finish                  │  │
│  │                                                     │  │
│  │    若无法本地处理 → 返回 null，走云端决策            │  │
│  │    连续 N 次本地决策 → 强制走云端（防死循环）        │  │
│  │                                                     │  │
│  └─────────────────────────────────────────────────────┘  │
│                          │                               │
│                          ▼ (null = 走云端)               │
│  ┌─ Step 3: AI 决策（AI Decision）─────────────────────┐  │
│  │                                                     │  │
│  │  视觉定位（如需）：                                  │  │
│  │    ├─ 外挂 3B 端侧模型（ExternalVisionProvider）     │  │
│  │    │     timeout=20s → 超时回退云端                 │  │
│  │    └─ 云端视觉模型（AiClient.visionLocate）          │  │
│  │        → 返回视觉坐标 (x, y)                         │  │
│  │                                                     │  │
│  │  CloudAgent.decideStream(snapshot, context)          │  │
│  │    ├─ 构造 prompt（含页面类型/上下文/历史步骤）       │  │
│  │    ├─ 流式调用 AI API（temperature=0.1）            │  │
│  │    ├─ 稳健 JSON 解析（extractJsonObject + 重试）     │  │
│  │    ├─ 超时保护（WATCHDOG_DECIDE_MS=45s）             │  │
│  │    └─ 反序列化 → AgentIntent                        │  │
│  │                                                     │  │
│  │  异常记忆查询（AnomalyMemoryEngine）：               │  │
│  │    指纹/标签命中 → 复用历史解决方案（跳过 AI 调用）  │  │
│  │                                                     │  │
│  └─────────────────────────────────────────────────────┘  │
│                          │                               │
│                          ▼                               │
│  ┌─ Step 4: 意图转译（Translation）────────────────────┐  │
│  │                                                     │  │
│  │  IntentTranslator.translate(intent, snapshot, visual)│  │
│  │    │                                                 │  │
│  │    ├─ 1. 获取授权模式                                 │  │
│  │    │     CapabilityManager.currentMode()             │  │
│  │    │     → SHIZUKU / ACCESSIBILITY / READONLY        │  │
│  │    │                                                 │  │
│  │    ├─ 2. 确定动作类型                                 │  │
│  │    │     IntentType.TO_ACTION[intent] → ActionType   │  │
│  │    │     例：open_app → launch                       │  │
│  │    │                                                 │  │
│  │    ├─ 3. 目标定位（对 tap/input/scroll_to）           │  │
│  │    │     IntentResolver.resolve(target, snapshot)    │  │
│  │    │       第一级 by=id → semanticId 精确匹配         │  │
│  │    │       第二级 by=text → 文字包含匹配              │  │
│  │    │       第三级 by=hint → 使用视觉坐标              │  │
│  │    │                                                 │  │
│  │    ├─ 4. 应用名→包名（对 open_app）                   │  │
│  │    │     AppNameResolver.resolve("微信")             │  │
│  │    │     → "com.tencent.mm"（运行时搜索已安装应用）   │  │
│  │    │                                                 │  │
│  │    ├─ 5. 通道选择（按授权模式）                        │  │
│  │    │     SHIZUKU    → type="shell", command="launch" │  │
│  │    │     ACCESSIBILITY → type="launch"               │  │
│  │    │     READONLY   → Failed（除 wait/write_doc）    │  │
│  │    │                                                 │  │
│  │    └─ 输出 AgentAction                               │  │
│  │                                                     │  │
│  └─────────────────────────────────────────────────────┘  │
│                          │                               │
│                          ▼                               │
│  ┌─ Step 5: 带验证执行（Verified Execution）───────────┐  │
│  │                                                     │  │
│  │  executeWithVerify(action, snapshot)                │  │
│  │    │                                                 │  │
│  │    ├─ 执行动作：                                     │  │
│  │    │     launch   → executor.launchApp(pkg)          │  │
│  │    │     tap      → executor.click(x, y)             │  │
│  │    │     long_press → executor.longClick(x, y)       │  │
│  │    │     type     → executor.typeText(text, target)  │  │
│  │    │     swipe    → executor.swipe(x1,y1,x2,y2)      │  │
│  │    │     key      → executor.back/home/recents()     │  │
│  │    │     wait     → delay(timeoutMs)                 │  │
│  │    │     shell    → ShizukuManager.exec(command)     │  │
│  │    │     scroll   → executor.scroll(elem, direction) │  │
│  │    │     task_done → 标记完成                        │  │
│  │    │                                                 │  │
│  │    ├─ 页面指纹验证（PageFingerprint）：               │  │
│  │    │     fingerprintAfter = PageFingerprint.compute()│  │
│  │    │     对比 fingerprintBefore vs After             │  │
│  │    │     有变化 → verified=true                      │  │
│  │    │     无变化 → 重试（最多 3 次）                   │  │
│  │    │                                                 │  │
│  │    ├─ 连续失败处理：                                 │  │
│  │    │     ≥3 次失败 → 请求用户介入（悬浮窗）           │  │
│  │    │     用户说"已手动处理" → 继续观察               │  │
│  │    │                                                 │  │
│  │    └─ 返回 VerifyResult{success, reason, before, after}│
│  │                                                     │  │
│  └─────────────────────────────────────────────────────┘  │
│                          │                               │
│                          ▼                               │
│  ┌─ Step 6: 记录与反馈 ────────────────────────────────┐  │
│  │                                                     │  │
│  │  记录到 _executionHistory                           │  │
│  │  追加对话历史（保持 MAX_DIALOG_TURNS=6 轮）          │  │
│  │  更新进度摘要（progressNotes，保持 MAX_PROGRESS_NOTES=3）│
│  │  悬浮窗更新进度                                     │  │
│  │  检查长时间无进展（5 分钟）→ 推送通知提醒            │  │
│  │                                                     │  │
│  └─────────────────────────────────────────────────────┘  │
│                          │                               │
│        ┌─────────────────┼─────────────────┐             │
│        ▼                 ▼                 ▼             │
│    ✅ 完成        ❌ 连续失败       🔄 继续下一步          │
│    task_done    ≥3次且用户介入    回到 Step 1           │
│    → DONE       → ERROR           → 直到 maxSteps       │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

## 六、授权模式说明

| 模式 | 条件 | 能力范围 |
|------|------|---------|
| **SHIZUKU** | Shizuku 服务已授权 | 全部能力：shell 命令 + 无障碍操作 |
| **ACCESSIBILITY** | 无障碍服务已开启 | 点击/滑动/输入/按键/启动应用 |
| **READONLY** | 两者都不可用 | 仅观察和分析，拒绝自动执行 |

模式切换由 [CapabilityManager](file:///d:/xkx/xkx_appproj/happy_phone%20agent/app/src/main/java/com/phoneagent/execution/CapabilityManager.kt) 实时监控，转译层据此选择执行通道。

## 八、UI 页面结构


## 九、关键设计原则

1. **意图与执行分离**：AI 只输出意图，端侧负责转译和执行通道选择
2. **端侧决策优先**：弹窗/广告/加载/异常/完成页本地处理，节省 API 调用
3. **带验证执行**：每次动作执行后通过页面指纹对比验证是否生效
4. **三态授权**：根据设备权限动态选择执行通道，降级 gracefully
5. **异常记忆复用**：命中历史异常指纹时直接复用解决方案，跳过 AI 调用
6. **上下文长度控制**：保留最近 6 轮对话 + 3 步进度摘要，避免上下文膨胀
7. **安全保护**：支付/银行页面强制 READONLY，敏感数据脱敏
8. **用户协作**：悬浮窗支持澄清/批准/指导/接管，人机协同完成任务
