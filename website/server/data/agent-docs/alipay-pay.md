# 支付宝付款

目标：把用户指定的金额付给正确的收款方，并在付款前后各做一次校验。付款是不可逆动作，**始终需要用户确认**。

## 前置条件

- 已确认收款方（商户名 / 收款人昵称）与金额；任一项缺失就先向用户澄清，不要猜。
- 确认当前支付宝登录的是用户本人的账号（我的 → 顶部昵称），不是则停止并提示。

## 标准流程

### A. 扫一扫付款（用户面前有收款码）

1. 首页右上角「扫一扫」→ 进入扫码页。
2. 若扫码页默认是「扫码」，直接对准二维码；若默认是「相册」，切回「扫码」。
3. 识别成功后进入付款确认页，页面会显示收款方与金额。
4. **校验**：核对收款方名称与用户给的一致；金额与用户给的一致（含小数点）。
5. 若金额需要手动输入：点金额区域 → 输入 → 收起键盘后再次核对。
6. 提交前停下，等待用户确认（needs_confirmation），不要自己点「确认付款」。

### B. 付款码付款（商户扫用户的码）

1. 首页点「付钱 / 付款码」→ 进入条形码 + 二维码页面。
2. 该码每分钟自动刷新，属敏感信息：不要截图留存、不要读出完整数字。
3. 让商户扫码；扣款前支付宝会弹出确认页。
4. **校验**：确认页上的商户名与金额；金额不符立即取消，不要点确认。
5. 付款成功页出现「支付成功」与金额后，任务才算完成。

### C. 转账给个人

1. 首页「转账」→ 选择「转给支付宝账户 / 手机号」。
2. 输入收款账号 → 点「下一步」→ 系统显示收款人真实姓名（脱敏）。
3. **校验**：姓名与用户描述一致；不一致就停止并让用户确认，绝不"大概是这个人"就继续。
4. 输入金额 → 备注可留空 → 提交前等待用户确认。

## 结果判定

- 成功：页面出现「支付成功 / 转账成功」且金额与预期一致；随后可点「完成」返回首页。
- 待验证：出现「处理中」时不要重复提交，等待页面自行落定，再读一次结果。
- 失败（余额不足 / 限额 / 风控）：把页面上的原文提示回报给用户，不要尝试换通道或拆笔绕过风控。

## 兜底

- 找不到「扫一扫」：从首页搜索框输入「扫一扫」，或在「更多」里找。
- 扫码长时间无反应：点扫码页相册入口也不行时，返回首页重进一次；两次失败就回报用户。
- 弹出更新 / 活动弹窗：先关闭（找 × 或「跳过」），不要点任何「立即领取」。
- 出现指纹 / 面容 / 密码验证：这是用户本人的验证，等用户完成，**不要代替用户输入支付密码**。

## 安全边界

- 不修改收款方、不修改金额为"文档建议值"——金额只能来自用户。
- 不加好友、不开通任何服务、不领取红包或优惠券，除非用户明确要求。
- 不在本流程内进行任何借贷、分期、充值操作。
